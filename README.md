# Quality-Aware Selective Enhancement for Low-Quality Face Recognition

## Pipeline Architecture

```
Input Image (crowded scene)
       │
  STAGE 1: RetinaFace ─── Detect & crop individual faces
       │
  STAGE 2: SHQS ────────── Score quality → NO / SOFT / STRONG
       │
       ├── NO (good)     → pass through as-is
       ├── SOFT (medium) → STAGE 3a: CLAHE  (only SOFT images)
       └── STRONG (bad)  → STAGE 3b: CodeFormer (only STRONG images)
       │
  MERGE ────────────────── Exactly one final image per face (no duplicates)
       │
  STAGE 4: ArcFace ─────── Embedding + cosine similarity → recognition
       │
  report.json
```

## Quick Start

### 1. Install dependencies

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Configure CodeFormer (optional)

Set the environment variable pointing to your CodeFormer installation:

```powershell
$env:CODEFORMER_ROOT = "C:\path\to\CodeFormer-master"
$env:CODEFORMER_PYTHON = "C:\path\to\CodeFormer-master\venv\Scripts\python.exe"
```

Or use `--skip-codeformer` to skip STRONG enhancement.

### 3. Build reference gallery (optional, for gallery mode)

Place reference face images in `Reference_Gallery/<person_name>/`:

```
Reference_Gallery/
    Alice/
        alice1.jpg
        alice2.jpg
    Bob/
        bob1.jpg
```

Then build:

```powershell
python run_pipeline.py --build-gallery
```

### 4. Run the pipeline

```powershell
# With a single reference image (1:1 comparison)
python run_pipeline.py crowd_photo.jpg --reference known_face.jpg

# With the pre-built gallery
python run_pipeline.py crowd_photo.jpg

# Skip CodeFormer (STRONG faces use original)
python run_pipeline.py crowd_photo.jpg --reference ref.jpg --skip-codeformer
```

### 5. Output

Results go to `pipeline_output/<image_name>/`:

```
pipeline_output/
    crowd_photo/
        raw/           # all accepted face crops (before enhancement)
        no/            # crops scored as NO (good quality)
        soft/          # crops scored as SOFT
        strong/        # crops scored as STRONG
        enhanced/      # final images after enhancement
        low_conf/      # rejected low-confidence detections
        report.json    # full pipeline report with recognition results
```

## Project Structure

```
pipeline/
├── run_pipeline.py              # Main entry point
├── requirements.txt             # Python dependencies
├── README.md                    # This file
├── stages/
│   ├── __init__.py
│   ├── stage1_retinaface.py     # Face detection & cropping
│   ├── stage2_shqs.py           # Quality assessment (SHQS scoring)
│   ├── stage3a_clahe.py         # SOFT enhancement (CLAHE)
│   ├── stage3b_codeformer.py    # STRONG enhancement (CodeFormer)
│   └── stage4_arcface.py        # Embedding, gallery, matching
├── models/                      # Model weights & gallery embeddings
│   └── reference_embeddings.npz # (generated by --build-gallery)
├── Reference_Gallery/           # Reference face images per person
│   └── <person_name>/           # Sub-folder per identity
└── pipeline_output/             # Pipeline results (auto-created)
```

## Key Design Decisions

- **No duplication**: CLAHE processes ONLY SOFT images. CodeFormer processes ONLY STRONG images. Each face appears exactly once in the final merge.
- **CodeFormer runs as a subprocess**: It has its own PyTorch/basicsr dependencies in a separate venv. The pipeline calls it via `subprocess.run()`.
- **Graceful fallback**: If CodeFormer fails for a face, the original crop is used.
- **Two matching modes**: single reference image (--reference) or pre-built gallery.
